# 柚月小手机增强（小白X记忆 + 智能滚动）

给「柚月小手机」补两个功能，一个扩展搞定。**不修改柚月小手机和小白X的任何文件**，两边更新都不会冲掉本扩展。

## 功能

### 1. 小白X记忆
柚月小手机里的 AI 请求（微信、朋友圈、微博、X、蜜语、日记等）是手机自己拼提示词，读不到小白X注入的记忆。
本扩展读取小白X最近一次给正文注入的记忆，在每次手机 AI 请求里多加一条 system 消息（位置在手机的「[Start a new chat]」分界线之前）。
- 可按 App 开关、限制最大字数、自定义前置说明句。
- 记忆按聊天保存一份副本，刷新页面后、还没生成过正文时也能用。

### 2. 通话智能滚动
语音通话、视频通话、电话App 通话中，手机每出一条 AI 气泡都会强制把页面拉到最底部。
本扩展改为：你停在底部才自动跟随；你往上翻看时不再拉你。你自己发消息时仍会滚到底部（可关）。

## 安装
扩展 → 安装扩展 → 填本仓库地址 → 刷新页面。
在扩展设置里找到「柚月小手机增强（小白X记忆 + 智能滚动）」，点「检查状态」自检。

## 如果你之前装过那两个单独的扩展
请**卸载** `Yuzuki Phone x LittleWhiteBox Memory Bridge`（记忆桥接）和 `柚月小手机 通话阅读优化` 再用本扩展。
旧「记忆桥接」的设置会在首次运行时自动迁移过来。

## 注意
- 记忆是小白X为「上一次正文生成」召回的那份，刚改完总结、还没生成新正文时手机用的是旧版。
- 每次手机请求会多出记忆的 token，不需要的 App 可以取消勾选。
- 若柚月小手机以后改了内部名称（`window.VirtualPhone.apiManager`、`callAI`、通话界面元素 id），对应功能会静默失效、恢复手机原样，不会报错。更新手机后点一次「检查状态」确认。
